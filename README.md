# DejiSa 🎵

**A modern Android music player with a custom Crystal interface.**

DejiSa brings local and network-based music together in a customizable Android music player.

## Download

**[⬇ Download the latest DejiSa APK](https://github.com/bigtechstruggler/DejiSa-Downloads/releases/latest)**

Latest release: DejiSa 3.50

## Features

* Local music library and offline playback
* Jellyfin music integration
* Network music sources: SMB, SFTP and FTP
* Internet radio
* DLNA / UPnP integration
* Sonic Core audio processing
* Custom Crystal interface and dock
* Music recognition integration with Vigilsoni
* Home screen widgets

## Installation

1. Download the latest APK from the Releases page.
2. Open the downloaded APK on your Android device.
3. Allow installation from your browser or file manager if Android requests permission.
4. Install and launch DejiSa.
